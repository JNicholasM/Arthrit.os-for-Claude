# Arthrit.os

A Windows 95 style desktop and block-programming controller OS for CC:Tweaked computers in Minecraft.

## Installing or updating in game

On any CC:Tweaked computer (Advanced Computer recommended), type:

```
wget run https://raw.githubusercontent.com/JNicholasM/Arthrit.os-for-Claude/main/release/install.lua
```

It installs the newest Arthrit.os, or updates an older one while keeping your files, controllers, scripts, desktop and settings. Then the computer restarts. Computers that already run Arthrit.os can also update from **Start > Update Arthrit.os...** without typing anything.

The `release` folder holds the packed OS (`arthrit.pak`), its version (`version.txt`), and the installer (`install.lua`).
